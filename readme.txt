Reproductor de Alcatraz Radio FM con modos compacto y completo, visualizador, ecualizador y barra inferior sincronizada.

== Installation ==

1. En WordPress vaya a Plugins > Añadir plugin > Subir plugin.
2. Seleccione el ZIP entregado e instálelo.
3. Active Alcatraz Radio Player.
4. Cree una página privada de prueba.
5. Inserte un bloque Shortcode.
6. Para modo compacto use: [radio_player mode="compact"]
7. Para modo completo use: [radio_player mode="full"]

== Important ==

Esta versión MVP admite una sola instancia funcional del shortcode por página.
No sustituya el reproductor actual del sitio hasta terminar la validación del plugin.
Consulte DOCUMENTACION_CLIENTE.md o INSTALACION_CLIENTE.html para la guía completa.
